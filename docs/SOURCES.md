# Sources du corpus

Documents écrits officiels lus pour relever les propositions. Les textes intégraux ne sont pas publiés dans ce dépôt (droit d'auteur) : ils sont conservés en copie locale et `scripts/telecharger-sources.sh` les reconstitue depuis les adresses ci-dessous. L'empreinte SHA-256 permet de vérifier qu'on relit le même texte.
